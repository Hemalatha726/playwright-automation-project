# Playwright Automation Project 🚀

## About the Project

This is my beginner-friendly browser automation testing project built using **Playwright** and **JavaScript**.

The goal is to learn and practice automated web testing across multiple browsers.

## 🛠️ Technologies Used

- JavaScript
- Playwright
- Node.js
- Visual Studio Code
- Git & GitHub

## 🌐 Browsers Tested

- Chromium
- Firefox
- WebKit

## 🧪 Test Cases

| Test Case | Description |
|---|---|
| Page Title Test | Verifies the page title |
| Get Started Test | Tests the Get Started link |
| Login Test | Tests successful login |
| URL Validation | Verifies successful login navigation |
| Heading Validation | Checks the successful login heading |

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Hemalatha726/playwright-automation-project.git
```

Navigate to the project:

```bash
cd playwright-automation-project
```

Install dependencies:

```bash
npm install
```

Install Playwright browsers:

```bash
npx playwright install
```

## ▶️ Run Tests

Run all tests:

```bash
npx playwright test
```

Run tests in Chromium:

```bash
npx playwright test --project=chromium
```

Run tests in Firefox:

```bash
npx playwright test --project=firefox
```

Run tests in WebKit:

```bash
npx playwright test --project=webkit
```

View the HTML report:

```bash
npx playwright show-report
```
